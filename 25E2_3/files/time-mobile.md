# Combinados - Time Mobile

## Convenção de Commits
Para manter a organização dos commits e MRs, nós adotamos as especificações do [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/).


## Convenção de CRs
Para auxiliar os membros do time a obterem maior conhecimento técnico e de regras de negócio, decidimos que um MR para ser mergeado deve ter o approve de outro integrante da equipe. Isso também é benéfico para a qualidade do código gerada.
