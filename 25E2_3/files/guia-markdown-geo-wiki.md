# Títulos
Como usar:
```
# Título 1 (principal)
## Título 2 (médio)
### Título 3 (menor)
#### Título 4 (pequeno)
##### Título 5 (bem pequeno)
###### Título 6 (minúsculo)
```

## HTML
```html
<!DOCTYPE html>
<html lang="pt-BR">
	<head>
		<meta charset="UTF-8">
		<meta name="viewport" content="width=device-width, initial-scale=1.0">
		<title>Olá mundo! Título</title>
	</head>
	<body>
		<h1>Olá mundo!</h1>
	</body>
</html>
```

````

<!DOCTYPE html>
````
