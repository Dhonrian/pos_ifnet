# Plantas Digitalizadas

Cada cidade que possuir a ferramenta de plantas digitalizadas precisará de uma configuração extra no arquivo ***applications.json*** para que a requisição às imagens das plantas seja possível.

Como exemplo, temos abaixo a configuração da cidade de Caçapava:

![caca_plantas.png](/caca_plantas.png)
> *applications.json*
{.is-info}


O parâmetro "mosaicURL" deve ser modificado para a URL de requisição de plantas digitais respectiva de cada cidade.
